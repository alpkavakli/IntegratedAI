Permissions

Your data

Everything stays on your computer. Updates of the extension and the agent server keep all of it.
  • In this browser (extension storage): …. Kept across updates. Removed if you uninstall the extension, so export it first.
  • On the agent server: connect to the server to see this. Kept across updates. Before an update changes the format, the server backs this folder up automatically.
Export/import moves your saved patches and settings to another copy of the extension (for example from a development copy to the Chrome Web Store version). The pairing token is never exported. Conversations and site memory stay in the server's folder; to back them up, copy that folder.
